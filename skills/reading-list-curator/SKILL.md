# Reading source curation

Read the strongest accessible source. For an X link, try `https://api.fxtwitter.com/<user>/status/<id>`, then an available browser or working mirror. Follow the linked destination when it contains the actual claim. Keep the incoming URL as the saved link and the destination actually read as the source URL.

Record retrieval methods, blocked sources and uncertainty. Preserve useful source text and archive links. Do not infer a whole article from its title, card or social summary. Use available browser and web tools without assuming any particular agent platform.

Capture concise grounded notes in `data/reading-log/` before promoting them to public content. Keep speculation separate from source claims. Prefer the topic vocabulary in `docs/maintainer-guide.md`. Create thematic digests from logged reading when requested or scheduled.

For a difficult source, consult the relevant historical fallback reference under `data/previous-agent-skills/reading-list-curator/references/` if the private data archive is available. Those files describe past tools; adapt the retrieval method to the current environment.

Read `AGENTS.md` first. Use paths relative to the project root. Load `skills/humanizer/SKILL.md` before publishing prose. Never use em dashes in outgoing writing.
